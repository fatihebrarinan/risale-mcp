## İngilizce taslak (Quran.com, Tanzil)

**Subject:** Non-commercial use of [your data] in a source-grounded AI tool for the Risale-i Nur

Dear [Quran.com / Tanzil] team,

My name is Fatih Ebrar İnan. I am building, as a personal and non-commercial project, a tool that lets AI models
such as Claude answer questions about Said Nursî's Risale-i Nur while citing the exact sentence they rely on.
The tool also includes a Qur'an layer so that verses quoted in the Risale can be shown and checked against the
Mushaf text.

[Quran.com: I used the API to fetch the word codes of 144 Mushaf pages (QCF v1) once, so that verses printed in
those fonts in one edition of the Risale could be identified. The responses are stored locally and the API is not
called again.]
[Tanzil: I use the Uthmani and simple texts unchanged, with attribution to the Tanzil Project and a link to
tanzil.net, as your license requires.]

The data is not republished: it is only read by the AI model while answering a question, on a password-protected
server used by me and one other person for development. There is no income from it. If I ever open it to a wider
audience I will ask you again. Please let me know if you have any concerns or conditions.

With thanks and best regards,
